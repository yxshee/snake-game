# ❓ FAQ — Snake Game

**Q: The game won't start!**
A: Make sure you have Python 3.10+ and Pygame installed. Run `pip install -r requirements.txt`.

**Q: How do I add my own snake skin?**
A: Place your PNG in `assets/images/` and update the code to use your image.

**Q: Can I play with a controller?**
A: Not yet, but it's a planned feature!

**Q: Where is my high score saved?**
A: In `highscore.txt` in the project root.
