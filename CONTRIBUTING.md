# Contributing to Snake Game 🐍

Thank you for considering contributing to this project! Your help makes the game better for everyone.

## How to Contribute
- **Report Bugs:** Open an issue with details and screenshots.
- **Suggest Features:** Propose new ideas or enhancements.
- **Submit Pull Requests:**
  1. Fork the repo and create your branch: `git checkout -b feature/your-feature`
  2. Commit your changes: `git commit -am 'Add new feature'`
  3. Push to the branch: `git push origin feature/your-feature`
  4. Open a pull request.

## Code Style
- Follow PEP8 for Python code.
- Keep code modular and well-commented.

## Community
- Be kind and respectful.
- All contributions are welcome!

Happy coding! 🎉
